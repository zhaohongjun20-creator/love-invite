# love-invite 💌

一个"躲不掉"的约会邀请页——发给心仪的人，让她在可爱风选项中完成一次约会邀约。

## 特色

- 🎀 **三步选择**：时间（7 选 + 自填）→ 地点（12 选 + 自填）→ 干什么（20 选 + 自填），全emoji可爱风
- 🏃 **会逃跑的拒绝按钮**：鼠标靠近/手指碰到就随机逃逸；真点中也只是换撒娇台词（"求求你了答应我好吗🙏""不要，我就要和你约会💢"共 9 句轮播），越点越小
- 🎵 **八音盒 BGM**：Web Audio API 现场合成（零版权/零外链），首次点击自动响起，可右上角开关
- 📋 **约会确认书**：选完自动汇总，一键复制告白文案 + 生成粉色清单卡片（canvas，长按保存发回）
- 🔔 **微信自动通知**（可选）：填入 [Server酱](https://sct.ftqq.com) SendKey，对方选完的瞬间你会收到微信推送
- 📱 手机/微信打开友好，单 HTML 文件，零依赖零构建

## 使用

1. （可选）用记事本打开 `love_invite.html`，把 `SEND_KEY = ""` 填入你的 Server酱 SendKey
2. 发送文件给对方（或部署到任意静态托管后发链接，体验更佳）
3. 等微信推送，去约会 💘

## 定制

选项/台词/配色都是纯 HTML+JS，直接编辑对应数组即可。
